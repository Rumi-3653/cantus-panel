# Conversation reading and mobile repair

- Bound catalog display titles to 300 characters while retaining every session and original history.
- Preserve the original project/provider when another provider continues a conversation.
- Keep source AI selected by default; show cross-provider continuation warning and a visible mobile picker.
- Refresh unavailable capabilities without dropping drafts; initialize cold catalogs before capability checks.
- Retry transient read errors once, discard stale platform responses, and reduce catalog polling to 15 seconds.
- Support paged compressed history and large internal tool results without expanding export limits.
- Treat only explicit terminal Claude quota errors as idle; unknown activity stays blocked.
- Compact the list toolbar without duplicating send/create handlers.
- Read bounded complete handoff history in one scan instead of rereading the whole source for every page.
- Reconcile lost send responses by request ID without retransmission or clearing a different draft.

Validation: npm test; node --test catalog-budget.test.cjs; npm run check:privacy.
Browser regression: set PLAYWRIGHT_MODULE and optionally CHROME_PATH, then run node --test cloud/repair-regression.test.cjs.
Missing original transcripts cannot be reconstructed by these fixes. Physical iPhone testing remains separate from browser viewport testing.
