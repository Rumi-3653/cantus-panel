# 桌面六項介面整合

這是原介面上的增量擴充。改名為 Weftelio 時只更新品牌文字與品牌字母；根目錄 14 個介面檔案扣除這些品牌替換後仍符合原雜湊，包含手機入口、原有腳本、外框與底色。桌面程式位於 `desktop/`，透過 `edition-ui.js` 依原有手機斷點選擇載入；手機不載入桌面樣式或 Task。

| 項目 | 位置與功能 |
| --- | --- |
| AI Workspace | 原有 Work、Lineage、Live 外框，另加桌面 Task。 |
| Agent Chat | Work：原生歷史、草稿、權限批准、送出、停止與綁定對話的排隊。 |
| Agent Steering | Work 底部：Codex 原生 `turn/steer` 插話、接收狀態、暫停、沿同一對話繼續。Claude 使用排隊，不聲稱支援相同插話功能。 |
| Agent Run | Work 右側「執行紀錄」：歷史回合、計畫、工具步驟、輸入輸出、錯誤、來源用量與成本；失敗步驟交給 AI 檢查後重試。 |
| Agent Tree | Lineage：明確的拆分關係、收合、自動縮放、原始尺寸、下拉選單內即時搜尋、底部緊湊的關係表單。 |
| Task Board | Task：四欄水平等寬縮放、拖曳排序、狀態、搜尋；詳情可編輯優先度、負責人、標籤與描述。 |

Work 與 Live 右側採同寬欄、同位置的兩個頁籤。Live 的機器清單放進右側「機器」，中間留給動態工作。

## 啟動與資料邊界

```bash
npm run start:desktop
```

預設原後端為 4589、桌面入口為 4591。若已有服務在運作，指定其他埠：

```bash
CANTUS_PANEL_PORT=4593 CANTUS_NEXT_PORT=4594 npm run start:desktop
```

示範模式不啟動任何 AI。連接來源仍使用根目錄的 `config/local.json`，先依 [SETUP.md](SETUP.md) 設定，再分別明確指定 `CANTUS_MODE=local` 與 `CANTUS_ENABLE_EXECUTION=1`。程式不自動尋找帳號、CLI 或遠端機器；工具批准維持手動。若設定了 Storage Guard，其拒絕結果會阻止寫入。

Task、桌面關係與新版獨立對話保存在忽略的 `state/desktop/`。原對話交由原後端寫入一次，不將進階指令偽裝成舊後端的其他操作。只有桌面新建的對話使用進階執行器。`CANTUS_PANEL_READ_ONLY=1` 同時鎖住 Task、關係及 AI 操作。

`CANTUS_NEXT_SQLITE_ROOT` 可另外指定支援 SQLite 鎖定的本機儲存路徑，預設 `state/desktop/runtime/`。請勿把執行狀態、對話、備份或本機設定提交到 Git。

## 控制語意

暫停會中斷目前回合；繼續是在同一原生對話啟動新回合，不會凍結作業系統或復原工具副作用。重試交給 AI 核對現況，不直接重播 shell。結果未確認、服務重啟或出錯時不自動重送。

用量優先取原工具回報的每回合累積差額；沒有基準時標示最近一次用量。成本只有來源回報時才顯示，不推算訂閱帳單。不保存內部思考文字。

## 驗證範圍

`npm test` 涵蓋原版測試與新增的 26 項桌面測試，共 77 項。新增測試包含示範及只讀模式、來源與 CSRF 限制、原後端單次轉送、Task 衝突與持久化、手機檔案雜湊、拆分圖、原生事件、插話去重、暫停與續作、用量及 AI 重試，以及閒置回合不重建目前對話。

公開分享版另以虛構資料驗證桌面操作與佈局，不呼叫真實 AI。其來源版本的獨立本機版已用真實 Codex 測過送出、批准、插話、暫停、同對話續作、重試及排隊；那份私人驗證紀錄不在此 repo。Claude 也已以獨立對話驗證真實回覆、工具輸出、用量、暫停，以及同一原生對話續作。手機以原檔雜湊及載入測試保護，未宣稱實體手機驗收或既有部署已升級。

完整隱私界線見 [PRIVACY.md](PRIVACY.md)。

Claude 的已確認中斷可能伴隨錯誤退出碼。此版只在匹配的中斷回覆、明確中斷終止事件、原生閒置狀態及結束程序全部確認時標示暫停，其他錯誤維持失敗。相容性背景見 [Claude Code 中斷事件回報](https://github.com/anthropics/claude-code/issues/94741)。
