# 隱私與發布邊界

這份儲存庫由明確挑選的來源檔案重新建立，不承接原有部署檔案或歷史。

## 不在儲存庫裡的內容

- 私人主機名稱、IP、SSH 設定、金鑰、隧道憑證與部署網域。
- 真實會話、客戶名稱、帳號、密碼、登入 cookie、token 與帳號資料庫。
- 本機完整設定、個人絕對路徑、執行狀態、備份與原始驗證記錄。

公開作者署名與第三方著作權聲明仍然保留，這些不是登入資料。

## 預設不接線

示範模式只使用 `demo.cjs` 的虛構內容。程式不自動尋找 CLI、讀取原有帳號或啟動遠端連線。讀取真實來源與啟動 AI 執行必須分別設定。

`.gitignore` 排除常見敏感檔案；`npm run check:privacy` 檢查已追蹤檔案中的敏感路徑、私網位址、金鑰與憑證格式。發布前仍需人工檢查 diff、圖片與 Git 歷史。忽略規則不能清除已提交的秘密，格式掃描也無法辨識所有私人內容。

## 已驗證與未驗證

42 項自動測試已在無外網的容器中通過；來源唯讀、環境清空，並限制記憶體、CPU、程序數、檔案大小、暫存空間與執行時間。測試只使用虛構資料，沒有呼叫真實 AI。

登入截圖來自登入版型的桌面與手機驗證。分享版另以虛構資料完成瀏覽器驗證，涵蓋右鍵更名、資料夾整理、合圖、模擬派工及返回工作端對話；不代表其他人的真實 CLI 帳號或新部署已通過驗證。圖片生成不代替這些驗證。

這是針對本次分享內容的隱私整理，不是完整安全稽核或零風險保證。
